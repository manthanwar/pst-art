## Future Version [2025/12/31](README.md)

### Upcoming New Features

* Add Unicode code page character encoding and simplify macros for character generation
* Add option to choose from (a) round dot matrix, (b) square pixels, or (c) other regular geometry shapes
* Add Microcontroller Displays
  * 16×2 and 16×4 displays showing 16 characters per row across 2 or 4 rows; ideal for basic status readouts and meters.
  * 20×4 display for larger text matrix offering 20 characters across 4 rows for more detailed text data.
* Add Computer Displays
  * 128x64 graphic monochrome pixel size display (2:1 aspect ratio) for drawing simple shapes, pixel art, and text.
  * 800x600 resolution super Video Graphics Array (SVGA) format (4:3 aspect ratio) computer display.
