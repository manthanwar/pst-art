# How to Compile?

The `pst-art` packages are created using LaTeX PostScript drawing package PSTricks that requires classic `tex -> dvi -> ps -> pdf` toolchain to build. They may not work efficiently using modern pdflatex, xelatex, lualatex, and friends. It is recommended you use one of the following compilation options to build your project.

## Using classic toolchain

Follow the classic toolchain: `latex -> dvips -> ps2pdf`

```bash
# Step 1: compile latex normally or with flags
latex file.tex
# Step 2: using dvips convert dvi to ps
dvips file.dvi
# Step 3: using ps2pdf convert ps to pdf
ps2pdf -dNOSAFER -dALLOWPSTRANSPARENCY file.ps 
# Step 5: view the pdf using pdf
pdf file.pdf
# Step 6: Repeat if mistakes
# Step 7: remove generated files
rm *.aux *.dvi *.fdb_latexmk *.fls *.log *.out *.ps
# Note: You may want to keep ps file for high-quality printing using printer's ps driver
```

## Using latexmk

Alternatively, you can use `latexmk`

```bash
latexmk -silent -pdfps -synctex=-1 -pvc -time file.tex
latexmk -c
latexmk -C
```

* -silent (or -quiet) suppresses most status messages and passes silent switches like -interaction=batchmode to underlying engines. Or you can use -f option Force latexmk to continue document processing despite errors. Normally, when latexmk detects that LaTeX or another program has found an error which will not be resolved by further processing, no further processing is carried out. Note: "Further processing" means the running of other programs or the rerunning of latex (etc) that would be done if no errors had occurred. If instead, or additionally, you want the latex (etc) program not to pause for user input after an error, you should arrange this by an option that is passed to the program, e.g., by latexmk's option -interaction=nonstopmode (which latexmk passes to *latex).
* -pdfps is for latex -> dvips -> ps2pdf toolchain
* -synctex=-1 or -synctex=1 is to enable forward and reverse search. It enables SyncTeX, a system that links your text code to the final PDF file. It creates a map so you can jump back and forth between your editor and PDF.
* -pvc is for preview continuously. It keeps latexmk running in the background to automatically recompile your LaTeX document and update your preview whenever you save changes to any of the source or dependency files.
* -time shows time used. On MS Windows, what is shown is clock time; on other systems CPU time. Clock time (wall-clock time) measures the total real-world elapsed time from start to finish, whereas CPU time measures only the active processing duration spent by the central processing unit. Clock time is generally longer because it includes waiting periods for disk input/output, network responses, or other programs.
* -c cleans up (removes) all regeneratable files generated by latex and bibtex or biber except dvi, postscript and pdf. These files are a combination of log files, aux files, latexmk's database file of source file information, etc.
* -C is same as the -c option with the addition of dvi, postscript and pdf files.

## Using makefile

```bash
 make -f ../../scripts/makefile file=pst-art-led runlatex
 make -f ../../scripts/makefile file=pst-art-led runlatex n=3
 make -f ../../scripts/makefile file=pst-art-led runlatexc
```

* makefile script is cmake script that can be adopted as it is or modified.
* file=file base name witout extension.
* runlatex to run latex once.
* runlatex n=x is to run latex x times.
* runlatexc to clean regenerated files.
  
## Suppress messages of fp package

The [nomessages] option in the LaTeX fp package prevents the package from printing status or computation messages to your log file and terminal output during math evaluations.

To suppress these messages, load the package in your document preamble using the following syntax:

```latex
\usepackage[nomessages]{fp}
```
